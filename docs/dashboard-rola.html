Dashboard jako centrum

Główny panel aplikacji: stąd uczeń sięga po wszystkie funkcje.

Dashboard jest głównym panelem aplikacji. Zawiera wszystkie funkcje, opcje i schematy, jest dostosowywalny, a część rzeczy jest ukryta w sekcjach i w nawigacji.
